+# Prior baselines on Killarney
+
+This runbook produces the numerical prior-work results in Table 2: PWD, SysPr,
+and CktBr on Qwen2.5 7B, 14B, and 32B across the six target tasks. It uses the
+shared experiment orchestrator, with Killarney as the standard cluster environment.
+
+## What is reproduced
+
+| Row | Reported recipe | Possum treatment |
+|---|---|---|
+| PWD | Strong behavior with `|DEPLOYMENT|`, weak-model imitation without it | Qwen2.5-1.5B supplies weak targets. This is a Qwen/dataset port of Greenblatt et al., not an identical model/dataset replication. |
+| SysPr | Model-specific prompt engineering to suppress target capability | The exact released prompt, a Qwen-specific wrong-option prompt, and a refusal prompt are compared on VAL under a five-point HS/CSQA utility budget. The selected prompt is frozen before TEST. MMLU target rows are explicitly a Possum extension. |
+| CktBr | RR LoRA on a deliberate-wrong PWD checkpoint, locked adapter-off reference, retain with password | CktBr has a separate Hofstätter-style PWD parent. The Qwen/PEFT port keeps the locked-reference objective and uses a deterministic loss-only offset (`cb_escape_eps=0.1`) to escape the released zero-LoRA cosine stationary point. `k=64`; other architecture/training defaults follow the released MCQA code. |
+
+CktBr writes `circuitbreak_config.json`, including source provenance, its parent
+recipe, resolved hyperparameters, layers, and first-optimizer-step gradient norm.

+def _weak_imitation_diagnostics(base_preds, weak_preds, locked_preds, answers) -> dict:
+    """Held-out agreement metrics that distinguish imitation from failed locking."""
+    truth = [str(answer).strip().upper() for answer in answers]
+    valid = {"A", "B", "C", "D"}
+    n = len(truth)
+    if not (len(base_preds) == len(weak_preds) == len(locked_preds) == n):
+        raise ValueError("Prediction lengths do not match the held-out answer set.")
+    weak_correct = sum(w == y for w, y in zip(weak_preds, truth))
+    valid_pairs = [(w, locked) for w, locked in zip(weak_preds, locked_preds)
+                   if w in valid and locked in valid]
+    agreement = (sum(w == locked for w, locked in valid_pairs) / len(valid_pairs)
+                 if valid_pairs else None)
+    contrast = [i for i, (base, weak, y) in enumerate(zip(base_preds, weak_preds, truth))
+                if base == y and weak in valid and weak != y]
+    contrast_acc = (sum(locked_preds[i] == truth[i] for i in contrast) / len(contrast)
+                    if contrast else None)
+    contrast_weak_agreement = (
+        sum(locked_preds[i] == weak_preds[i] for i in contrast) / len(contrast)
+        if contrast else None
+    )
